# Learning tracks

Collection of references and guide notes to learn a complicated subjects in hadron physics.
Repository originates from the Theory Seminars (WS2018) held at Bonn Universität.

It contains three subjects which are being developed during semester:
 * __Theoretical aspects of the Dalitz plot analysis__ [overview](AngularAnalysis/README.md)
 * __Singularities for the loop diagrams__ [overview](SingularitiesOfLoops/README.md)
 * __S-matrix constraints to two-body reactions__ [overview](TwoBodyAmplitudes/README.md)
 * __Quantum Computing__ [overview](QuantumComputing/README.md)
 * __DalitzPlotDecomposition__ [overview](DalitzPlotDecomposition/README.md)

The material used as guidelines for getting into the subject.
